# أبشري | Abshri

منصة عربية لتحليل شكاوى الطالبات واكتشاف المشكلات المتكررة بمعالجة اللغة الطبيعية.
مشروع ختامي لبرنامج **NLP From Zero** — Google Developer Groups on Campus، جامعة الأميرة نورة بنت عبدالرحمن.

An Arabic NLP platform that turns student complaints (MSA or Saudi dialect) into recurring, explainable problem categories.

## ما يعمل في الموقع
- **تقديم شكوى:** نموذج بسيط مع تحليل حي أثناء الكتابة (النص بعد التوحيد، الكلمات المفتاحية، درجات الفئات).
- **لوحة التحليل:** عدد الشكاوى، توزيع الفئات، الكلمات والعبارات المتكررة، الفئات حسب الكلية، مثال يمثّل كل فئة، الاتجاه الأسبوعي، بحث وتصفية وترتيب.
- **كيف يعمل التحليل:** خطوات المعالجة وتقييم المصنّف محسوباً مباشرة على ٦٠ شكوى مصنّفة يدوياً.

كل التحليل يعمل داخل المتصفح (`assets/abshri-nlp.js`)، ولا يُرسل النص لأي خدمة خارجية، ولا يحتاج حساباً.

## خطوات التحليل
1. التوحيد: إزالة التشكيل والتطويل، توحيد أ/إ/آ، ة→ه، ى→ي، الأرقام الهندية، اختصار الحروف المكررة.
2. التقطيع وحذف الرموز والإيموجي.
3. تجذيع خفيف (نزع «ال» وأخواتها) وحذف كلمات التوقف (فصحى ولهجة سعودية).
4. تصنيف بمعجم كلمات مُرجّح لثماني فئات (قوية = ٢، ضعيفة = ١، صفر = غير مصنّفة).
5. تجميع: تكرار الكلمات والعبارات، التوزيع حسب الكلية، أوضح مثال لكل فئة.

الملف `assets/abshri-nlp.js` نسخة سطراً بسطر من دفتر Colab (`abshri_nlp.py`)، وأعطت النسختان نتائج متطابقة على ٦٩ نصاً.

**التقييم** (٦٠ شكوى: ١١ من النسخة الأولى و٤٩ مكتوبة للاختبار، ليست شكاوى حقيقية): دقة ٨٣٫٣٪، Macro-F1 = 0.85. نموذج TF-IDF مع انحدار لوجستي حصل على ٤٣٫٣٪ على البيانات نفسها.

## التخزين
**الافتراضي (دون إعداد):** تُحفظ الشكوى في متصفح الزائرة (localStorage). يعمل لأي شخص دون حساب.
الحدود: كل متصفح يرى شكاواه فقط مع البيانات التجريبية. لجمع شكاوى من عدة أجهزة استخدمي «تصدير/استيراد JSON» في لوحة التحليل.

**اختياري — قاعدة بيانات مشتركة (Supabase، مجانية):**
1. أنشئي مشروعاً في supabase.com.
2. SQL Editor ← نفّذي `supabase/schema.sql`.
3. Authentication ← Users ← Add user (بريدك وكلمة مرور قوية)، ثم نفّذي:
   `insert into public.admins (email) values ('بريدك');`
4. Authentication ← أوقفي «Allow new users to sign up».
5. Project Settings ← API: انسخي Project URL و anon public key إلى `config.js`.

الزائرات يستطعن الإرسال فقط؛ القراءة لحساب المسؤولة المسجّلة فقط (RLS). مفتاح anon علني بطبيعته، **ولا يوضع مفتاح service_role في أي ملف**.

## التشغيل محلياً
```
python3 -m http.server 8000
```
ثم افتحي http://localhost:8000

## الملفات
| الملف | الدور |
|---|---|
| `index.html` | الصفحة |
| `assets/abshri-nlp.js` | معالجة اللغة (مطابقة للدفتر) |
| `assets/app.js` | الواجهات واللوحة |
| `assets/storage.js` | التخزين: المتصفح أو Supabase |
| `assets/demo-data.js` | ٦٠ شكوى تجريبية موسومة |
| `config.js` | إعداد Supabase الاختياري |
| `supabase/schema.sql` | الجدول وسياسات الأمان |

مشروع طلابي، وليس قناة رسمية لاستقبال الشكاوى في الجامعة.
